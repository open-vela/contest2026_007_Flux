# 信息台 InfoPlat

## 一、作品简介

信息台 InfoPlat 是一款面向 800x600 方形屏开发板的 Xiaomi Vela JS 快应用信息集散中心。它为智能手表用户提供新闻、天气、快递查询等实用信息的聚合服务，采用简洁的卡片式 UI 设计，支持深色模式切换，让用户在小屏设备上也能高效获取所需信息。

**解决的问题：** 智能手表屏幕小，用户需要快速获取关键信息但不想打开多个应用。

**亮点：** 一站式信息聚合、小屏深度优化、深色模式支持、模块化架构设计。

## 二、选题方向

**快应用 / 手表应用创新**

选择理由：
1. 智能手表市场快速增长，用户对轻量级应用需求旺盛
2. 快应用开发框架成熟，适合快速原型开发
3. 信息聚合类应用具有广泛用户基础和实用价值
4. 小屏优化挑战能体现技术深度

## 四、运行方式

### 环境准备
1. 安装 Node.js >= 8.10
2. 安装 aiot-toolkit：`npm install -g aiot-toolkit`

### 开发调试
```bash
# 进入快应用目录
cd quickapp/hello_quickapp

# 安装依赖
npm install

# 启动开发服务器
npm run start
```

### 构建打包
```bash
# 构建项目
npm run build

# 打包发布
npm run release
```

### 部署到设备
1. 使用 aiot-toolkit 连接模拟器或真机
2. 扫码或手动安装快应用包
3. 在手表上启动"信息台"应用
